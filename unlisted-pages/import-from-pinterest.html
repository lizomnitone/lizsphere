📌 Import Images from Pinterest

How to use:
  • Copy the URL of a Pinterest board you want to import
  • Paste it below and select which category to add the images to
  • Click "Download & Import" and wait for the process to complete
  • The gallery manifest will be updated automatically
Example: https://ca.pinterest.com/lizmdrewcalgs/art-design/
